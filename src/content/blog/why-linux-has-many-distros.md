## 1. 리눅스는 하나의 완성된 운영체제 이름이 아니다
Windows는 Microsoft라는 하나의 회사가 운영체제 전체를 개발하고 배포한다.
따라서 다음과 같이 하나의 제품 계열 안에서 버전이 올라가는 구조를 가진다.
- Windows 10
- Windows 11
- Windows Server 2019
- Windows Server 2022
반면 Linux는 일반적으로 **운영체제 전체가 아니라 운영체제의 핵심 부품인 커널(Kernel)**을 의미한다.
커널은 다음과 같은 역할을 담당한다.
- CPU와 메모리 관리
- 프로세스 실행 및 관리
- 디스크와 파일 시스템 관리
- 네트워크 통신
- 키보드, 디스크, 네트워크 카드 등의 하드웨어 제어
- 응용 프로그램과 하드웨어 사이의 중재
하지만 커널만으로는 사용자가 실제로 사용할 수 있는 완전한 운영체제가 되지 않는다.
운영체제로 사용하려면 Linux 커널 외에도 다음과 같은 구성 요소가 필요하다.
- 명령어와 셸
- 시스템 관리 도구
- 라이브러리
- 패키지 관리자
- 설치 프로그램
- 네트워크 도구
- 보안 도구
- 데스크톱 환경
- 각종 응용 프로그램
즉, 우리가 서버에 설치하는 Ubuntu, Rocky Linux, Debian 등은 Linux 커널에 여러 프로그램과 관리 도구를 결합하여 만든 **완성된 운영체제 제품**이다.
이러한 운영체제를 **리눅스 배포판(Linux Distribution)**이라고 한다.

## 2. 리눅스는 통일되지 못한 것이 아니라 자유롭게 구성할 수 있는 구조이다
Linux 커널은 오픈 소스로 공개되어 있다.
따라서 특정 회사만 Linux를 만들 수 있는 것이 아니라, 라이선스 조건을 지키는 범위에서 여러 기업과 조직이 Linux 커널을 가져다가 자신들의 목적에 맞는 운영체제를 만들 수 있다.
각 조직이 중요하게 생각하는 목적은 서로 다르다.
예를 들면 다음과 같다.
- 기업 서버에 적합하도록 안정성과 장기 지원을 강조
- 일반 사용자가 쉽게 사용할 수 있도록 데스크톱 환경을 강조
- 최신 기술과 최신 패키지를 빠르게 도입
- 오래된 컴퓨터에서도 실행할 수 있도록 최소화
- 보안 테스트나 네트워크 분석에 특화
- 컨테이너나 클라우드 환경에 적합하도록 경량화
- 임베디드 장비에 맞게 필요한 기능만 포함
따라서 Linux가 여러 종류로 나뉜 것은 하나로 통일하는 데 실패했기 때문이 아니다.
오히려 **하나의 공개된 Linux 커널을 바탕으로 여러 조직이 서로 다른 목적의 운영체제를 만들 수 있기 때문에 다양한 배포판이 존재하는 것**이다.

## 3. 배포판마다 무엇이 다른가?
각 배포판을 만드는 조직은 다음과 같은 사항을 직접 결정할 수 있다.
### 사용할 Linux 커널 버전
최신 커널을 빠르게 사용할 수도 있고, 충분히 검증된 이전 버전을 장기간 유지할 수도 있다.
기업용 서버 배포판은 일반적으로 최신 기능보다 안정성을 중요하게 생각하므로, 비교적 오래된 커널을 사용하면서 필요한 보안 수정 사항만 별도로 반영하기도 한다.
### 기본으로 제공할 패키지
웹 서버, 데이터베이스, 개발 도구, 데스크톱 프로그램 등 어떤 소프트웨어를 기본으로 제공할지 결정할 수 있다.
### 패키지 형식과 패키지 관리자
배포판 계열에 따라 소프트웨어를 설치하고 관리하는 방식이 달라진다.

예를 들어 Rocky Linux에서는 일반적으로 다음과 같이 패키지를 설치한다.
```plain text
dnf install nginx
```
Ubuntu에서는 다음과 같이 설치한다.
```plain text
apt install nginx
```
설치되는 nginx 프로그램의 본질은 비슷하지만, 프로그램을 내려받고 설치하며 업데이트하는 관리 체계가 다르다.
### 새로운 버전의 출시 주기
최신 기능을 빠르게 반영하기 위해 짧은 주기로 새 버전을 출시할 수도 있고, 기업 운영의 안정성을 위해 긴 주기로 출시할 수도 있다.
### 지원 기간
배포판마다 보안 업데이트와 유지보수를 제공하는 기간이 다르다.
일반 사용자용 배포판은 지원 기간이 짧을 수 있고, 기업용 배포판은 장기간 지원을 제공하기도 한다.
### 기술 지원 제공 여부
어떤 배포판은 무료로 사용할 수 있지만 공식적인 기업 기술 지원이 제공되지 않는다.
반면 Red Hat Enterprise Linux와 같은 상용 배포판은 구독 계약을 통해 공식 기술 지원, 보안 패치, 인증된 소프트웨어 환경 등을 제공한다.
### 보안 체계
배포판에 따라 기본적으로 사용하는 보안 체계가 다를 수 있다.
- RHEL 계열: SELinux를 주로 사용
- Ubuntu 계열: AppArmor를 주로 사용
### 데스크톱 환경
그래픽 화면을 제공하는 데스크톱 환경도 배포판이나 설치 옵션에 따라 달라질 수 있다.
- GNOME
- KDE Plasma
- Xfce
- Cinnamon
이처럼 동일한 Linux 커널을 기반으로 하더라도, 배포판을 만드는 조직이 어떤 구성 요소와 정책을 선택하느냐에 따라 서로 다른 운영체제가 만들어진다.
